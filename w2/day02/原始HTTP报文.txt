发送 HTTP 请求报文（HTTP/1.1）
请求行：GET /get HTTP/1.1
Host 头：目标域名（虚拟主机必备）
User-Agent：客户端标识 curl/8.17.0
Accept: */* 接受任意类型响应

GET /get HTTP/1.1\r\n
Host: httpbin.org\r\n
User-Agent: curl/8.17.0\r\n
Accept: */*\r\n
\r\n
拆解四段：
请求行：GET /get HTTP/1.1
    方法：GET
    资源路径：/get
    HTTP 版本：HTTP/1.1
请求头（多行键值对）
    plaintext
    Host: httpbin.org
    User-Agent: curl/8.17.0
    Accept: */*
空行 \r\n ✅【分隔标记！必须有】，告诉服务器：请求头结束，后面是请求体
请求体：GET 请求这里是空，什么都没有
注意：HTTP 协议换行是 \r\n（回车 + 换行），不是单纯\n。在 wireshark 抓包里能看到。
